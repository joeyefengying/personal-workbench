## 三条最容易走错的路（先记住）

1. **别把 L4 模块当成「一个系统」**。一个「应付报账」背后是前端工程、后端应用、池表结构、会计引擎规则、权限项、流程节点六件套。
2. **别把「单据状态」和「审批状态」混为一谈**。单据状态只有草稿/审批中/已完成/已作废；审批状态有 10 种（含挂起、异常、退回至发起人）。前端做状态映射时两套必须分开。
3. **别在没配会计主体和账簿之前碰任何报账功能**。单据一旦要记账，缺会计主体/账簿就是死路，且错误会带进期初和期末。
