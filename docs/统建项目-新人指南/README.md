## 这套文档是怎么来的

全部内容来自**五矿统建知识库（知微 · 财务管控库）**：**26 组问题、约 13.1 万字原始答案**，含引用来源（原件标题 + 分块/页码）与 **12 张原文截图**。原文保存在 `.ekko-tmp/kb/kb-answers/`，可逐条追溯。

知识库答不上、或**文档之间自相矛盾**的地方，我们**没有编造**，统一标成「⚠️ 待核实」，并在 [16 线下索取清单](./16-线下索取清单.md) 里写明该找谁要什么。

## 三条最容易走错的路（先记住）

1. **以为「单据状态」就是「审批状态」** —— 单据状态 4 态（草稿/审批中/已完成/已作废），审批状态 10~11 态，两套枚举，前端必须分开映射。
2. **以为「凭证生成」是保存后就有的** —— 凭证生成节点常挂在**审批节点**上，且规则没配时只弹「当前单据类型未配置凭证生成规则」，不生成任何东西。配置顺序错了会一路空跑。
3. **以为某个接口/字段的语义是唯一确定的** —— 金额精度、(26,6)、(18,2)、(36,10) 三套并存；「允差」字段有两套官方定义。**凡遇到这类冲突，先查 [16 索取清单](./16-线下索取清单.md)，别自己拍。**

## 维护方式

- **补问知识库**：`python .ekko-tmp/kb/kb_run.py f`（`a`平台全景 `b`组织人员 `c`配置实施 `d`设计理念 `e`前端接入 `f`实施下钻）。问答按问题文本断点续跑，同一问题不会重复花时间。
- **改完 md 重新打包**：`python docs/build_docs_html.py` → 生成同目录 `index.html`（单文件，双击即看）。
- **新增一篇**：在 `docs/build_docs_html.py` 的 `DOCS` 列表里加一行（文件名, 导航标题, 分组），再在本文档目录表补一行。
- **内容有疑问**：先查 `.ekko-tmp/kb/kb-answers/*.json` 的原始答案与引用，再看该篇末尾「待确认项」。
